# 고정 Tiny 보컬 검수 런타임 검증 — 2026-11-11

제품 Tiny CLI와 관측 검증 경로를 Vocadito 원본 40곡에서 실행했다. 40곡 모두 추론과 관측 검증을 완료했고 실패는 없었다. 이 결과는 Tiny를 **검수 개발 기준**으로 선택한 근거이며, 자동 음높이 교정이나 최종 제품 품질 승인이 아니다. 이후 [실제 다섯 곡 생성·출력과 복제 Job 삭제 후 보존](FIXED_TINY_FIVE_PRODUCT_2026-11-11.md)도 완료했다. 별도의 fresh 검증 API도 다섯 곡에서 각각 새 Demucs와 Tiny를 실행해 완료했다. 원곡 정확도·최소 수정 품질 판정은 여전히 미완료다.

## 런타임과 관측

검증한 제품 소스는 commit `7a07c88b9c4f1267431d2daf372c7b3acbd8b602`이다. Python 3.11, torchcrepe 0.0.24, resampy 0.4.3, librosa 0.11.0, torch 2.7.1을 사용했다. Tiny 가중치 SHA-256은 `d4993eea36ed1a0ad9ac549c740dae5265b049ce72004f00c2f59e01c0be8432`이다. 각 곡은 CPU 두 스레드의 새 프로세스에서 실행했고 Python random·NumPy·torch seed를 각각 0으로 초기화했다. 입력과 코드 등 165개 해시의 전후 불일치는 없었다. 상세 코드·입력·receipt 해시는 함께 제공되는 JSON에 기록했다.

모델의 55–880Hz 설정은 출력의 엄격한 절단값이 아니다. 실제 Tiny 출력에서 54.169Hz와 881.142Hz가 관찰됐다. 검증기는 모델의 20센트 bin과 ±20센트 dither에서 유도한 범위를 허용하며, 출력값을 자르거나 수정하지 않는다. 관측 시간은 10ms 간격을 검증한다.

첫 곡의 기존 Tiny 캐시와 시간축은 정확히 같았으나 Hz 배열은 완전히 같지 않았다. 이전 음표 calibration은 모델을 상주 프로세스에서 준비하면서 NumPy seed를 지정하지 않아 SciPy dither의 난수가 고정되지 않았다. 새 제품 CLI는 곡마다 seed를 초기화한다. 별도의 기존 CPU 후보 공식 `run()`은 NumPy seed를 설정했다. 이 차이만으로 모델의 우열을 판정하지 않는다.

## 40곡 음높이 관측

다음은 40곡별 frame 지표의 산술 평균이다. 기존 원본 Hz 주석을 사용했으며 원음의 전문 검수 정답이나 전체 제품 점수는 아니다.

| 지표 | 40곡 macro |
|---|---:|
| Raw Pitch Accuracy | 0.8800 |
| Raw Chroma Accuracy | 0.8815 |
| Overall Accuracy | 0.8318 |
| Voicing Recall | 0.8938 |
| Voicing False Alarm | 0.2749 |

사람 A1/A2의 원본 Hz를 가장 가까운 반음으로 변환한 검수 대리 음표 4,113개 중 2,920개를 관측하고 1,193개를 보류했다. 관측된 음표의 전체 경고는 223개이며 그중 옥타브 경고는 5개였다. 이는 대리 음표에 대한 검수 calibration이며 자동 수정 근거가 아니다.

## 실제 파트 선택 조건

같은 새 F0 관측을 기존 캐시의 raw YourMT3·MR-MT3 악보 80개에 직접 선택기로 적용하면 YourMT3는 33개 선택·7개 보류, MR-MT3는 40개 보류였다. 이 단계는 AMT 모델을 새로 실행하지 않았다. 직접 선택기의 33개 성공 부분집합 점수를 전체 40곡 향상으로 취급하지 않는다.

고정 레시피의 `_main_part`는 음표가 있는 파트가 하나뿐이면 선택기를 호출하지 않는다. 이 실제 조건을 적용하면 YourMT3 40곡은 **단일 파트 우회 39곡, Tiny 선택 1곡**으로 모두 처리됐고 기존 선택 파트와 40/40 같았다. 직접 선택기가 보류했던 7곡도 모두 단일 파트 우회에 해당한다. 우회 결과는 보컬이 음향적으로 확인됐다는 뜻이 아니다. MR-MT3는 복수 파트 40곡 모두 보류였으며, 보류를 실패로 유지하고 40곡 분모에 0점으로 넣으면 F1은 0이다.

YourMT3의 선택 파트가 바뀌지 않은 40곡 전체 macro F1은 A1 onset 0.4957, onset+offset 0.2711, A2 onset 0.5907, onset+offset 0.3463이다. 40곡 모두에서 나온 값이며 선택 성공 부분집합의 점수가 아니다.

## 검증 범위

관련 focused 테스트는 이 작업의 독립 테스트에서 52개 통과·2개 건너뜀(FFmpeg 부재), 별도 root 검증에서 55개 통과였다. 선택 작업의 공개 API 초기화 순서를 바로잡은 최신 통합 그룹은 기존 subset을 포함해 61개 통과·건너뜀 0개였다. 이 집계들은 합산하지 않는다. 실제 다섯 곡의 새 모델 실행·출력은 완료됐고, 별도 fresh 검증 API는 다섯 곡 모두 실행·원음·악보·revision 보존을 확인했으며, [곡별 관측과 경고](FIXED_TINY_FIVE_PRODUCT_2026-11-11.md#fresh-acoustic-validation)는 advisory다. 전체 음악 품질 판정은 후속 작업이다. 원본 음표는 변경하지 않았고, Tiny 관측은 주선율 선택과 advisory 검수에만 사용한다.

기존 공개 연구의 방법과 전체 후보 결과는 [CPU 후보 결과](CPU_PUBLIC_VOCADITO_RESULTS_2026-11-10.md)와 [Tiny 음표 검수](CREPE_NOTE_REVIEW_2026-11-10.md)를 참조한다.
