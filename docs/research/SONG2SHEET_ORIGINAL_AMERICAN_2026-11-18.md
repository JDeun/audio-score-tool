# Song2Sheet 원본 보컬 경로: 전곡 1곡 비교

고정된 Song2Sheet 원본 [`6aee2a2139b28af871f4c9a878b7e18650c38226`](https://github.com/kishormorol/song2sheet/tree/6aee2a2139b28af871f4c9a878b7e18650c38226)의 CLI를 동일한 174.32초 혼합 원음 한 곡(American Idiot)에 실제 실행했다. `--no-isolate`를 사용하지 않아 원본 `htdemucs_6s` 분리를 CPU에서 실행했고, 음원 자르기·힌트·곡별 파라미터 조정은 하지 않았다. 원본의 180초 제한을 넘는 나머지 4곡은 전곡 결과인 것처럼 잘라서 평가하지 않았다. 원본 실행과 종료 후 독립 평가에서 고정 소스·모델·입력의 변경이 없음을 확인했다.

macOS arm64의 별도 Python 3.11 환경에서 seed 0, Torch 2 threads로 실행했다. 원본 요구사항을 만족하도록 해석한 환경이며 upstream의 고정 lock 재현이라고 주장하지 않는다. 실행에 사용한 **84개 패키지의 정확한 버전**, 모델·평가 영수증 SHA 및 집계값은 [JSON](SONG2SHEET_ORIGINAL_AMERICAN_2026-11-18.json)에 기록했다. 런타임 버전은 실행 전 기록과 실제 설치 메타데이터에서 일치했다.

## 연주 MIDI 비교

같은 커뮤니티 GP5 편곡의 보컬 310음을 사용하고, 드럼만으로 미리 구한 `원음초 = 0.28 + 0.9838 × 악보초` 정렬을 양쪽에 적용했다. 음높이 50센트와 시작 허용 오차 50/100ms를 적용했고, 종료 조건은 기준 음 길이의 20% 또는 50ms 중 큰 값이다. Song2Sheet는 원본이 저장한 필터 적용 MIDI 274음(velocity 45 이상, 직렬화 전 최소 50ms)을, 기준은 고정 YourMT3 선택 MIDI 311음을 평가했다. 이는 원본 6-stem 분리를 포함한 Song2Sheet 전 과정 보컬 결과와 AST 기준 보컬 결과의 비교다. 분리 경로와 출력 정책이 달라 AMT 모델만 분리한 비교가 아니다.

| 지표 | YourMT3 선택 MIDI F1 | Song2Sheet 원본 MIDI F1 |
|---|---:|---:|
| 시작 50ms | 0.6860 | 0.3596 |
| 시작·종료 50ms | 0.5668 | 0.2021 |
| 시작 100ms | 0.7279 | 0.5000 |
| 시작·종료 100ms | 0.5990 | 0.2774 |

이번 고정 원본 보컬 경로는 네 지표에서 비교 기준보다 낮아 최종 채택하지 않는다. 이 한 곡은 개발에 재사용한 녹음이며 커뮤니티 편곡과 드럼 기반 정렬은 전문가 정답이나 완벽한 원곡 전사가 아니다. 이 결과를 Song2Sheet 전체나 다른 악기·녹음의 성능으로 일반화하지 않는다. 사람의 수정 횟수·시간은 측정하지 않았다.

## 악보와 사용 조건

원본 MusicXML에는 137마디, 음높이 기호 324개, 쉼표 275개, tie 시작 52개, 동시 발음의 후속 음표 23개와 화성 기호 0개가 기록됐다. 원본 MIDI는 220 PPQ이며 한 tick은 약 2.273ms다. 그러나 원본 출력에는 원음 기준 beat/downbeat 시각과 조건부 pickup 이동이 남지 않아 악보와 기준의 정확한 시간·기보 일치도는 **평가 불가**다. 원본 CLI가 저장한 PDF는 없었다. 반환된 SVG 2쪽은 별도 실험 harness가 캡처한 것이며 CLI가 저장한 산출물이나 PDF로 표시하지 않는다. 별도 공통 렌더러 PDF는 2쪽이었고 시각 검토에서 큰 음역 점프, 반음 임시표와 쉼표가 보였으나 정확도를 승인하지 않았다. 이것은 원본 PDF가 아니며 주 비교에는 원본 MIDI를 그대로 사용했다. 코드·키 정확도와 최종 출판 품질도 검증하지 않았다.

Song2Sheet 저장소의 MIT 표시는 모든 가중치에 자동 적용되지 않는다. Demucs 기여자는 [사전학습 가중치가 MIT 대상이 아니며 과학 목적용이라고 설명](https://github.com/facebookresearch/demucs/issues/327)했다. 이 설명은 6-stem 출시 이전이므로 해당 체크포인트의 개별 조건은 확인되지 않았고 연구용으로만 취급한다. StringNet과 Basic Pitch의 개별 가중치 조건도 독립 확인하지 못했다. [BeatThis 고정 소스 README](https://github.com/CPJKU/beat_this/blob/b95c8ab0c58c2d9fcfd40508ae8dffbc05ac4f5c/README.md#license)는 공개 모델 가중치에 MIT를 명시하되 학습 파일은 별도 조건일 수 있다고 설명한다.
