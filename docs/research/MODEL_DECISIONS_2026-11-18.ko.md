## Chordino + power profile: 이번 고정 설정은 채택하지 않음

[집계 JSON](CHORDINO_POWER_CPU_RESULTS_2026-11-18.json)에 실행과 비교의 해시,
분모, 제외 구간을 기록했다. 공식 nnls-chroma `4c5f214a75cb354f8d8c933e161377c5b4d83713`
(GPL-2.0-or-later)의 알고리즘과 기존 18개 profile을 유지하고 root/fifth profile 하나만
추가했다. CPU에서 같은 dictionary·설정으로 원본 mixed WAV 5곡을 전부 실행했다.
각각 exit 0, 입력·동결 파일 불변이다. native 알고리즘은 단일 스레드다.

직접 만든 C5/C/Cm 합성음의 고정 1.5–6.5초 평가에서는 구성음·근음이 모두 일치했다.
이는 이상적인 입력에서 power 출력을 할 수 있다는 확인이다. 실제 곡 비교는 다음과 같다.

FANCY는 63화음·85.679/85.742초다. 15.623ms 겹침은 모든 모델에서 별도 작성 구간
관측으로 동일하게 센다. Me는 지원하는 11화음·14.027/14.1초이고 suspended 4화음
(5.074/5초)은 diatonic reference 변환 범위 밖이라 제외했다. American의 42.739초는
두 rhythm guitar가 power를 연주하고 bass root가 일치하는 작성 구간이다. 전체 mix의
전문가 화성 정답이 아니다. N과 빈 구간도 reference 분모에 포함했다.

Chordino는 American에서 근음 일치를 높였지만 exact power 일치는 0.263초뿐이었다.
FANCY에서는 major/minor reference에 power를 출력한 시간이 11.572/11.618초였다.
따라서 이번 설정은 최종 화성 후보에서 제외한다. 모든 Chordino 설정의 불가능성을
주장하거나 결과를 보고 profile을 재조정하지 않는다. 제품 기본값도 변경하지 않는다.
한국어 두 곡의 전곡 화성 정답, 전체 WCSR, 사람의 수정량은 검증되지 않았다.

## DBN: 연주 시각과 악보 리듬을 구분

[박자 재검증 JSON](BEAT_DBN_NOTATION_REASSESSMENT_2026-11-18.json)에 집계를 기록했다.
American의 고정 drum-only source 정합과 310음 community vocal 악보를 사용했다.
두 출판물의 붙임줄을 합치고 각 clock의 첫 음악적 downbeat로 악보 원점을 고정했다.
보컬 예측에 맞춘 원점·템포 최적화는 하지 않았다.

| 악보상의 정확 일치 | 기존 S2 clock | DBN clock |
| --- | ---: | ---: |
| 음높이 + 4분박 단위 시작 | 63 | 157 |
| 음높이 + 시작 + 음가 | 39 | 95 |

두 경로는 같은 YourMT3 311음 중 같은 3음을 누락하고 308음을 표현했다. 모든 표현 음의
시작·끝은 각 격자에서 원본 MIDI 경계에 가장 가까웠다. 다른 ID 선택이나 시작점 우선
재배치가 원인은 아니었다. 재연주 MIDI와 해석의 최대 차이는 3µs였다. DBN은 50ms
연주 시각 일치를 낮추면서도 악보의 박자·음가 일치를 개선했다. 두 지표를 대체하지
않으며 이 결과를 근거로 격자를 더 촘촘하게 하거나 음가 보정 규칙을 추가하지 않는다.

## Me So Bad의 첫박 불확실 근거 정정

기존 `[2,42,37,1]`은 **minimal 디코더 자신의 beat 목록**에서 센 downbeat 순번이다.
S2 표도 DBN 위상 충돌도 아니었다. minimal은 317박, DBN은 338박으로 누락·추가된
박이 순번을 바꿨다. 원시 downbeat peak를 DBN 박에 80ms 이내 연결하면 79개가 같은
위상에 놓이고 4개는 연결되지 않는다. 같은 신경망에서 나온 동의이므로 독립 정답은 아니다.

별도의 작성자 후렴 8마디 시작을 기존 두 시간 투영으로 대조했다. 고정 100 BPM 투영에서
minimal·DBN은 모두 8/8이 70ms 이내였다. 작성자 끝점 투영에서는 150ms 이내가 각각
8/8이고 S2는 5/8이었다. 두 Beat This 경로 모두 가장 가까운 quarter pulse가 downbeat였다.
이 부분 근거는 인트로나 전곡의 위상을 입증하지 않는다. DBN의 첫 관측은 7.52초이며
그 앞 13박은 외삽이다. 잘못 읽은 minimal 표로 Me만 S2로 돌리는 조건을 만들지 않는다.

DBN의 별도 runtime 연결·사전 검사와 실제 제품 통합을 진행한다. 최종 출시 판단에는
5곡의 원곡 정확도, 출판 가독성, 사람의 수정량 검증이 계속 필요하다.
