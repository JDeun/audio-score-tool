# 인라인 키와 MIDI 템포 변환 검증

`109f339e610541812fd1a248edbb094d1f200413`의 인라인 키 parser 및 MIDI 24-bit 템포 범위 검사를 사용해 캐시된 5곡을 다시 변환했다. 입력은 Beat This 박자와 SheetSage2 구조를 결합한 별도 hybrid ABC·해석 결과이며, 기존 main의 SheetSage2 기본 모델 실행과 다른 맥락이다. 정규화 코드는 포함하지 않았고 새 모델 추론이나 PDF 렌더는 실행하지 않았다.

총 2,813개 어택의 음높이와 시간은 해석 결과와 일치했고 onset·offset 차이는 각각 2ms 이내였다. 이는 변환 보존 검사이며 원곡 정확도나 출판 품질 승인이 아니다. 이전 나의 노래 control 영수증은 어택 수 불일치 실패를 기록한다. 당시 607 대 605라는 별도 진단은 해당 영수증에 숫자로 기록돼 있지 않다.

[메타데이터](INLINE_KEY_AND_MIDI_TEMPO_2026-11-11.json)에 입력 맥락과 결과 해시, 두 소스의 실행 전후 및 Git 원본 일치, 검증 스크립트의 실행 전후 일치와 보고서 해시를 기록했다. 소스 원본과 캐시 입력은 변경하지 않았다. 구문·템포 범위의 별도 회귀 검사와 이 실곡 변환 검사는 서로 다른 증거다.
